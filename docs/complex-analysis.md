# Анализ комплекса: первая реализация

## Интерфейс

Докинг → Анализ комплекса → загрузка PDB → Анализировать взаимодействия.
Требуется готовый комплекс белка и одной позы малого органического лиганда.
Выбора позы нет. Если органических компонентов несколько, нужно выбрать лиганд
по имени, цепи и номеру остатка. Распространённые добавки и вода исключаются.
Фильтр добавок не доказывает биологическую роль выбранного компонента.

Результаты: таблица контактов, CSV в UTF-8 с BOM, диаграмма SVG/PNG с формулой
лиганда, подписями остатков и привязкой линий к атомам/центрам групп.
Фильтр типов влияет только на диаграмму. Полный CSV сохраняет все пять типов.
Пустой список контактов — корректный результат, а не ошибка.

## Расчёт

PLIP запускается отдельным процессом с тайм-аутом 90 секунд во временной папке.
Он получает только загруженный PDB: сетевого поиска и загрузки структур нет.
PLIP добавляет водороды; геометрия тяжёлых атомов не оптимизируется.
Используется --nofix, чтобы сохранять нумерацию атомов; поэтому некорректные
файлы требуют исправления пользователем, а не скрытого автоматического ремонта.
После завершения временная папка удаляется. Результаты хранятся только в сессии.

Типы: водородная связь, гидрофобный контакт, солевой мостик, π–π, катион–π.
В таблице отдельно указано определение расстояния. Отчёт PLIP сопоставляется
с выбранным остатком, а атомные номера — с загруженным PDB. RDKit строит
2D-копию восстановленного PLIP лиганда по SMILES и проверяет покрытие/элементы
атомного отображения. При неоднозначности таблица остаётся доступной,
диаграмма не выводится. PDB не гарантирует правильность порядков связей и
протонирования: они требуют корректной предварительной подготовки комплекса.

## Зависимости и запуск

Существующий requirements.txt не изменён. До установки requirements-analysis.txt
в том же Python-окружении необходимо установить рабочие Python bindings Open Babel.
PLIP 2.4.0 выбран как фиксированная версия с известной схемой XML. Его установка
проверяет наличие Open Babel; простой системный исполняемый файл obabel недостаточен.
Порядок установки и платформенные особенности:
https://github.com/pharmai/plip/tree/v2.4.0

После настройки окружения:

```text
python -c "from openbabel import pybel; print('Open Babel OK')"
python -m pip install -r requirements.txt
python -m pip install -r requirements-analysis.txt
python -c "from plip.structure.preparation import PDBComplex; print('PLIP OK')"
python -m unittest discover -s tests -p test_complex_analysis.py -v
streamlit run app/main.py
```

На Streamlit Cloud сначала нужно проверить установку Open Babel в окружении
хостинга. Один файл requirements-analysis.txt сам по себе не включает функцию
на хостинге: зависимости должны быть установлены в среде приложения. До этого
новая вкладка выдаёт понятное сообщение о недоступном анализаторе, два прежних
режима продолжают работать. Проверка развёртывания ещё не выполнена.

## Ограничения первой версии

- Один малый органический лиганд представлен одним остатком, до 300 тяжёлых атомов.
- До 10 МБ и 80 000 атомов в файле; до 40 отображаемых остатков на диаграмме.
- Многомодельные PDB, альтернативные положения и коды вставки отклоняются явно.
- Составные/пептидные лиганды, ковалентные аддукты не входят в проверенный сценарий.
- Исправление химической структуры отдельным SMILES/SDF пока не реализовано.
- Подписи новой вкладки пока русские; существующие переводы не менялись.
- Геометрические контакты не являются прогнозом аффинности.

## Проверка в текущем сеансе

24 автономных теста прошли (15 новых и 9 существующих): валидация PDB, разделение компонентов, исключения,
пять типов контактов, направление водородной связи, атомные номера, CSV,
тайм-аут, отсутствие зависимостей и удаление временных файлов.
Данные тестов синтетические, запуск PLIP в них подменён контролируемым ответом.
Один тест реального RDKit-рисунка пропущен: в среде нет RDKit.
PLIP/Open Babel и Streamlit здесь также отсутствуют; полный анализ реального
комплекса, визуальный вид диаграммы и UI ещё не проверены. Установка зависимостей
в этом сеансе не удалась. Эти проверки обязательны до использования студентами.

Изменения перенесены в исходный репозиторий BioSynth-EDU.
